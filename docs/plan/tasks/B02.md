# B02 — Wspólny klient administracyjny

Status: odebrane

ID i powiązane kryteria epica: B02, #7/#10; szczegóły w macierzy.

Cel: Wspólny klient administracyjny.

Zależności: K00.

Pliki do odczytu: crates/core/src/endpoint.rs; apps/ctl/src/main.rs; apps/server/src/main.rs shutdown.

Pliki do zmiany — zamknięta lista: crates/core/src/admin_client.rs; apps/ctl/src/main.rs.

Istniejące symbole i miejsca integracji: wait_for_server_stop; run ctl.

Ustalony kontrakt wejścia/wyjścia: request(&ServerEndpoint,&str)->io::Result<String> zwraca tekst OK lub Err; stop_and_wait(&Path,&ServerEndpoint)->io::Result<()>; protokół AUTH + command, odpowiedź do EOF.

Wymagane zachowanie i limity: Connect 2s, cała odpowiedź/write 3s, max 64KiB; wait max 120s; status shutdown legacy port TAB OK/ERR; sprawdzić zanik właściwego endpointu i wyłącznej blokady instancji; nigdy tokenu w logu.

Warunki odbioru implementacji: CTL używa biblioteki; błąd zapisu nie daje sukcesu; stop związany z endpointem tokenem i portem.

Scenariusze późniejszej weryfikacji: Slow-drip, zły token, save failure, restart instancji.

Zakazane rozszerzenia zakresu: zmiana protokołu v8/zapisu v3, testy i obciążenie, nowe funkcje poza kontraktem, commity/push/GitHub, cudze pliki. Unsafe, manifesty, moduły i integrację pętli wykonuje koordynator. Nie uruchamiaj cargo workspace ani cargo fmt --all. Raportuj zależności zamiast edycji cudzych plików.
